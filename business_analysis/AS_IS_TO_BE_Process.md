# AS-IS / TO-BE Process Improvement

## AS-IS risk pattern

```text
Separate public reports / spreadsheets
        ↓
Manual copying of statistics
        ↓
Different definitions used by departments
        ↓
Untraceable assumptions
        ↓
Management discussion based on inconsistent numbers
```

## TO-BE process

```text
Authoritative source register
        ↓
Controlled raw tables
        ↓
Reproducible Python / SQL transformation
        ↓
Governed KPI dictionary
        ↓
Executive scorecard + Excel scenario model
        ↓
Management decision + documented assumptions
        ↓
Quarterly refresh / validation
```

## Business improvement
The redesigned process separates factual source data from assumptions, reduces repeated manual reconciliation, provides one metric definition set and creates an auditable path from source to recommendation.

## Production extension
When internal university data becomes available, add enquiry, application, registration, fee-collection and programme-capacity facts. This will allow the external market score to be validated against actual conversion performance instead of remaining a market-screening model.
